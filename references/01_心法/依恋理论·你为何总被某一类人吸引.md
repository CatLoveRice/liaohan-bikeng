# 依恋理论·你为何总被某一类人吸引

## 1. 核心观点/金句
> 你不是"眼光有问题"，而是你的依恋模式在替你选择。改变模式，才能改变结局。

## 2. 底层逻辑 (为什么？)

依恋理论源于英国心理学家约翰·鲍比（John Bowlby），最初用于解释婴儿与照顾者之间的情感纽带，后被扩展到成人恋爱关系。成人依恋主要分为三种类型：

### 安全型（约50%）
- **特征**：能坦然亲近，也接受适度独立；信任他人也信任自己
- **恋爱表现**：沟通直接、情绪稳定、不惧承诺、不惧失去
- **吸引力**：容易吸引所有人，但最吸引焦虑型（因为安全型提供的稳定感是焦虑型的"情绪氧气"）

### 焦虑型（约20%）
- **特征**：渴望亲密，害怕被抛弃，需要大量 reassurance
- **恋爱表现**：容易过度付出、频繁查看消息、患得患失
- **核心恐惧**："我不够好，他终会离开"
- **吸引力陷阱**：极易被回避型吸引 → 形成"追逃循环"

### 回避型（约25%）
- **特征**：重视独立，害怕被控制，亲密后想逃离
- **恋爱表现**：忽冷忽热、需要个人空间、不擅长表达情感
- **核心恐惧**："靠得太近我会失去自我"
- **吸引力陷阱**：容易被焦虑型的热情吸引，但亲密后又想推开

> 还有约5%为**恐惧型（紊乱型）**：既渴望亲密又害怕受伤，行为最不可预测。

### 焦虑 × 回避：最致命的吸引力

```
焦虑型：靠近！靠近！我需要确认你还在！
                  ⬆        ⬇
回避型：后退！后退！我需要呼吸的空间！

    这是一个相互激活的"追逃陷阱"
    焦虑越追 → 回避越逃 → 焦虑更焦虑 → 回避更回避
```

**为什么这个组合最常见？**
- 焦虑型和回避型各自的行为**相互印证了对方的深层恐惧**
- 焦虑型把回避型的"需要空间"解读为"他不爱我了" → 更用力地追
- 回避型把焦虑型的"靠近需求"解读为"她要控制我" → 更用力地逃

## 3. 具体操作 (怎么做？)

### 如果你是焦虑型倾向

- **第一步：识别触发器** —— 觉察哪些行为会触发你的焦虑（如：对方回消息慢了、周末没约你）
- **第二步：延迟反应** —— 焦虑上头时，给自己一个"24小时冷静期"再做出反应
- **第三步：自我安抚话术** —— "我的焦虑是我的课题，不是他的错。我可以等一等。"
- **第四步：扩展社交圈** —— 把情感需求分散到多个支点（朋友、爱好、事业），而非全部押注在一个人身上

### 如果你是回避型倾向

- **第一步：识别逃跑信号** —— "当我感觉'窒息'时，是真的对方过分了，还是我的回避机制被激活了？"
- **第二步：练习"微小靠近"** —— 每天主动做一件小的亲近行为（主动发一条消息、说一句"今天想你了"）
- **第三步：设定边界，而非冷暴力** —— 学会说"我需要周末独处充充电，周一我们再聊"，而不是直接消失
- **第四步：记录"靠近后的结果"** —— 客观判断"靠近他后，我真的失去自我了吗？"

## 4. 正向案例 vs 反向案例

- **❌ 错误示范**：小A（焦虑型）发现男友回消息变慢，开始每天发小作文质问"你是不是不爱我了"，男友（回避型）感到窒息后提出分手。
  - **错误原因**：焦虑行为激活了回避型的逃跑机制，双方都没有觉察自己的模式。
- **✅ 正确示范**：小A觉察到自己的焦虑后，在备忘录写下"这是我的焦虑在说话"，然后去做了一组瑜伽。第二天男友主动联系解释最近项目忙。小A平静回应"辛苦了，忙完找我"。
